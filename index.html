🔑 API 키 발급 방법 (무료, 5분)
1. ai.google.dev 접속 → Get API key 클릭
2. Google 계정으로 로그인
3. Create API key → 키 복사
※ 무료 한도: 하루 1,500회 (월 VOC 분석엔 충분)
🧠 Claude Code CLI 연결 방법
1. Python 3.10+ / Node.js LTS 설치
2. npm install -g @anthropic-ai/claude-code
3. ai-bridge 폴더에서 start-ai-local.bat 실행
4. 아래 주소를 확인하고 연결 확인을 누르세요
※ 본인 Claude 구독 계정의 사용량(토큰)이 소모됩니다. 창을 닫으면 AI 기능이 멈춥니다.
💻 Ollama 로컬 AI 사용 방법
1. ollama.com 에서 Ollama 설치
2. 터미널에서: ollama pull exaone3.5:7.8b
3. CORS 허용: OLLAMA_ORIGINS=* ollama serve
※ 인터넷 연결 불필요 · 데이터 외부 전송 없음
서버 주소: http://localhost:11434 (고정)
