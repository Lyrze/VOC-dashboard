🔑 API 키 발급 방법 (무료, 5분)
1. ai.google.dev 접속 → Get API key 클릭
2. Google 계정으로 로그인
3. Create API key → 키 복사
※ 무료 한도: 하루 1,500회 (월 VOC 분석엔 충분)
💻 Ollama 로컬 AI 사용 방법
1. ollama.com 에서 Ollama 설치
2. 터미널에서: ollama pull exaone3.5:7.8b
3. CORS 허용: OLLAMA_ORIGINS=* ollama serve
※ 인터넷 연결 불필요 · 데이터 외부 전송 없음
